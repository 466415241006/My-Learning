# My-Learning

Repo รวมโปรเจคและบันทึกการเรียนรู้ส่วนตัว ใช้สำหรับฝึกเขียนโค้ดและทดลองเทคโนโลยีใหม่ ๆ แต่ละโปรเจคจะแยกโฟลเดอร์ของตัวเอง และมี `README.md` อธิบายรายละเอียดของโปรเจคนั้นโดยเฉพาะ (เป้าหมาย, เครื่องมือที่ใช้, หลักการทำงาน, วิธีรัน)

## รายการโปรเจค

| **โปรเจค** | **คำอธิบายสั้น ๆ** | **เครื่องมือหลัก** | **สถานะ** |
|---|---|---|---|
| [`weather-app-API/`](./weather-app-API) | เว็บแอปเช็คสภาพอากาศแบบเรียลไทม์ ผ่าน REST API | Node.js, Express, Open-Meteo API | 🟢 ใช้งานได้ |

## หมายเหตุเรื่อง Git หลายเครื่อง

Repo นี้อาจถูก push จากหลายเครื่อง แต่ใช้ email เดียวกัน (ตั้งค่าผ่าน `git config user.email`) ส่วนการยืนยันตัวตน (SSH key / token) ตั้งแยกต่อเครื่อง
